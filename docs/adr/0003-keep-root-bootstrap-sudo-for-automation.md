# 0003 - Keep Root Bootstrap Sudo for Automation

## Status

Not implemented

## Context

Review report: `.sf-plugin/review/review-report-2026-05-05-2.md`, finding R-0000324
Workflow: $sf-apply-review

## Decision

Keep the `NOPASSWD:ALL` sudo rule generated by root-bootstrap projects for now because Paratix
still requires automated root privileges for certain planned tasks.

## Rationale

The developer's note on the finding states that this is "on purpose" because Paratix still needs
automated root privileges for certain TODOs. It requests documenting this in an ADR and asks for a
more detailed description if the requirement can be solved differently.

An alternative solution should be designed only after it is clear which root operations must
remain automated after bootstrap and which can be limited to specific commands or a later cleanup
step.

## Source Finding

R-0000324 from `.sf-plugin/review/review-report-2026-05-05-2.md`: Root-bootstrap projects
permanently generate a sudoers file with `NOPASSWD:ALL` for the admin user. After bootstrap, there
is no generated cleanup and no restriction to specific commands. Compromise of the admin SSH key
therefore leads directly to unrestricted root access without an additional barrier.
